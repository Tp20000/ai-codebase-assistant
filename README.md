# AI Codebase Assistant v2.0

Upload your codebase. Ask anything. Get AI-powered answers using RAG + Agents.

## Quick Start

‍‍powershell
git clone https://github.com/yourname/ai-codebase-assistant
cd ai-codebase-assistant
./scripts/dev-start.ps1
‍‍

## Services

| Service    | URL                       |
|------------|---------------------------|
| Frontend   | http://localhost:5173      |

## Stack

Backend: FastAPI, PostgreSQL, Redis, ChromaDB, LangChain, Ollama, Celery
Frontend: React 18, TypeScript, Vite, TailwindCSS, Monaco Editor, React Flow
